# AGENTS.md — шаблон для проекта

Скопируй в корень проекта как `AGENTS.md` и заполни. Файл читается агентом в каждой сессии: пиши факты, не пожелания. Пустой раздел лучше удалить, чем оставить с заглушкой. Секреты сюда не входят — только имена переменных.

Для пайплайна особенно полезны разделы «Команды», «Потребители и контракты», «Рисковые места». Неизвестное отмечай явно; отсутствие раздела не запрещает исследовать проект. Не копируй шаблон в чужой проект без необходимости.
