Получи список задач из Bitrix24 по роли и покажи пользователю.

## Шаги

1. **Определи роль** из запроса пользователя:
   - «что на мне», «мои задачи», «где я исполнитель» → `responsible`
   - «что я поставил», «где я постановщик» → `creator`
   - «где я соисполнитель» → `accomplice`
   - «где я наблюдатель» → `auditor`
   - по умолчанию → `responsible`

2. **Определи фильтр статуса** (опционально):
   - «активные», «незакрытые», «в работе» → `active`
   - конкретный статус числом (2..7) → это число
   - без уточнения → не передавай (покажет все)

3. **Запусти скрипт** `scripts/list_tasks.py`:

```bash
python "<каталог этого скила>/scripts/list_tasks.py" <role> [status]
```

Примеры:
- `list_tasks.py creator active` — задачи, где я постановщик, не завершённые
- `list_tasks.py responsible` — все, где я исполнитель

4. **Выведи пользователю** компактный список: `#ID — Название (статус, дедлайн)` + ссылку на каждую: `https://biocard.bitrix24.ru/company/personal/user/169/tasks/task/view/<ID>/`

## Роли (фильтр tasks.task.list)

- responsible → RESPONSIBLE_ID
- creator → CREATED_BY
- accomplice → ACCOMPLICE
- auditor → AUDITOR

## Статусы

- 2 — ждёт выполнения
- 3 — выполняется
- 4 — ожидает контроля
- 5 — завершена
- 6 — отложена
- 7 — отклонена
- `active` — все, кроме завершённых (5)

## Требования к окружению

Скрипт требует переменную окружения `BITRIX_WEBHOOK` (webhook Bitrix24 вида `https://<портал>/rest/<user_id>/<token>/`). Если переменная не задана, скрипт завершится с ошибкой — сообщи пользователю, что нужно задать `BITRIX_WEBHOOK` (см. README репозитория ai_agents_harness). Не пытайся подобрать или захардкодить значение.
