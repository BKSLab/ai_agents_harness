Заверши (закрой) задачу в Bitrix24 по ID.

## Шаги

1. **Определи task_id** из запроса пользователя.

2. **Если задача заменена другой** — сначала добавь комментарий через `bitrix-comment-task` со ссылкой на новую задачу, потом закрывай.

3. **Запусти скрипт** `scripts/close_task.py`:

```bash
python "<каталог этого скила>/scripts/close_task.py" <task_id>
```

4. **Выведи пользователю** подтверждение и ссылку из вывода скрипта.

## Примечание

- Использует метод `tasks.task.complete` → статус 5 (завершена).
- Действие обратимо в интерфейсе Битрикса (задачу можно переоткрыть).
- Перед закрытием убедись, что всё содержание задачи действительно отработано или перенесено — не закрывай задачу, часть которой ещё актуальна (как было с #14073).

## Требования к окружению

Скрипт требует переменную окружения `BITRIX_WEBHOOK` (webhook Bitrix24 вида `https://<портал>/rest/<user_id>/<token>/`). Если переменная не задана, скрипт завершится с ошибкой — сообщи пользователю, что нужно задать `BITRIX_WEBHOOK` (см. README репозитория ai_agents_harness). Не пытайся подобрать или захардкодить значение.
