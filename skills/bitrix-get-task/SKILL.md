Получи задачу из Bitrix24 по ID и покажи её пользователю.

## Шаги

1. **Определи task_id** — из сообщения пользователя (число после # или просто число).

2. **Получи задачу** через скрипт `scripts/get_task.py`:

```bash
python "<каталог этого скила>/scripts/get_task.py" <task_id>
```

3. **Выведи пользователю** структурированную информацию:
   - Название и статус
   - Описание (полностью)
   - Ответственный, постановщик
   - Дедлайн (если есть)
   - Ссылку на задачу: `https://biocard.bitrix24.ru/company/personal/user/169/tasks/task/view/<ID>/`

## Статусы задач

- 2 — ждет выполнения
- 3 — выполняется
- 4 — ожидает контроля
- 5 — завершена
- 6 — отложена

## Приоритеты

- 2 — высокий
- 1 — средний
- 0 — низкий

## Требования к окружению

Скрипт требует переменную окружения `BITRIX_WEBHOOK` (webhook Bitrix24 вида `https://<портал>/rest/<user_id>/<token>/`). Если переменная не задана, скрипт завершится с ошибкой — сообщи пользователю, что нужно задать `BITRIX_WEBHOOK` (см. README репозитория ai_agents_harness). Не пытайся подобрать или захардкодить значение.
