Создай задачу в Bitrix24 на основе текущего контекста разговора.

## Шаги

1. **Проанализируй контекст** — что обсуждается, какая проблема или фича требует фиксации.

2. **Сформируй описание задачи** на русском языке:
   - Что нужно сделать и зачем (бизнес-контекст)
   - Текущее состояние / проблема
   - Конкретные шаги реализации (если можно определить)
   - Релевантные файлы и фрагменты кода (с путями и номерами строк)
   - Возможные варианты решения с плюсами/минусами (если несколько подходов)
   - Технические ограничения или зависимости

3. **Создай задачу** через скрипт `scripts/create_task.py` из директории скила.

   Скрипт принимает title и description как позиционные аргументы, а ID рабочей группы/проекта — необязательным параметром `--group-id`. Если группа не указана пользователем, не передавай параметр: задача создаётся как раньше, без `GROUP_ID`.

```python
import subprocess, sys, os

SKILL_DIR = r"<каталог этого скила>/scripts"  # абсолютный путь: каталог, где лежит SKILL.md, + /scripts

title = "Название задачи"
description = """Многострочное
описание задачи с [B]BBCode[/B]"""
group_id = None  # Например, 521; оставь None, если группа не нужна.

command = [sys.executable, os.path.join(SKILL_DIR, "create_task.py"), title, description]
if group_id is not None:
    command.extend(["--group-id", str(group_id)])

result = subprocess.run(
    command,
    capture_output=True,
    env={**os.environ}
)
print(result.stdout.decode("utf-8"))
if result.returncode != 0:
    print(result.stderr.decode("utf-8"))
```

   Запускай через Bash tool:
```bash
python -c "<код выше>"
```

4. **Выведи пользователю** ссылку на созданную задачу из вывода скрипта.

## Требования к описанию

- Язык: русский
- Название: глагол + объект, конкретно (пример: "Добавить инструмент get_delivery_status в Tim Bot")
- Структура: заголовки разделов через BBCode ([B]Заголовок[/B]), код в блоках [CODE]...[/CODE]
- Варианты решения нумеровать и давать рекомендацию
- Пути к файлам — ТОЛЬКО относительные внутри проекта (например, `agent/config/playbooks/client_prod.yaml`). Абсолютные пути запрещены: они некорректно отображаются в Битриксе и бессмысленны для других участников.

## Поля Bitrix24 tasks.task.add

- TITLE — название (обязательное)
- RESPONSIBLE_ID — ответственный (обязательное), всегда 169
- DESCRIPTION — описание задачи, поддерживает BBCode
- PRIORITY — приоритет: 2=высокий, 1=средний, 0=низкий
- DEADLINE — крайний срок в ISO 8601 (если нужен)
- PARENT_ID — родительская задача (если подзадача)
- GROUP_ID — ID рабочей группы/проекта (необязательно; передавать через `--group-id`)
- ACCOMPLICES — соисполнители (массив ID)
- AUDITORS — наблюдатели (массив ID)

| Имя | ID |

- "соисполнители — Иван и Семен" → ACCOMPLICES: [14345, 8361]

## Требования к окружению

Скрипт требует переменную окружения `BITRIX_WEBHOOK` (webhook Bitrix24 вида `https://<портал>/rest/<user_id>/<token>/`). Если переменная не задана, скрипт завершится с ошибкой — сообщи пользователю, что нужно задать `BITRIX_WEBHOOK` (см. README репозитория ai_agents_harness). Не пытайся подобрать или захардкодить значение.
