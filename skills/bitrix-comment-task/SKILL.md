Добавь комментарий к задаче в Bitrix24.

## Шаги

1. **Определи task_id** — из сообщения пользователя (число после # или просто число).

2. **Определи текст комментария** — из сообщения пользователя или текущего контекста разговора.

3. **Отправь комментарий** через скрипт `scripts/comment_task.py`:

```python
import subprocess, sys, os

SKILL_DIR = r"<каталог этого скила>/scripts"  # абсолютный путь: каталог, где лежит SKILL.md, + /scripts

task_id = 12345  # ID задачи
text = "Текст комментария"

result = subprocess.run(
    [sys.executable, os.path.join(SKILL_DIR, "comment_task.py"), str(task_id), text],
    capture_output=True,
    env={**os.environ}
)
print(result.stdout.decode("utf-8"))
if result.returncode != 0:
    print(result.stderr.decode("utf-8"))
```

Запускай через Bash tool:
```bash
python -c "<код выше>"
```

## Требования к тексту комментария

- Пути к файлам — ТОЛЬКО относительные внутри проекта (например, `agent/config/playbooks/client_prod.yaml`). Абсолютные пути запрещены.
- Разметка — ТОЛЬКО поддерживаемые BB-коды Битрикса (см. ниже). Markdown ([**text**], [# заголовок], [```code```]) Битрикс не понимает.

## Поддерживаемые BB-коды Битрикса

### Форматирование текста
- `[b]...[/b]` — жирный
- `[i]...[/i]` — курсив
- `[u]...[/u]` — подчёркивание
- `[s]...[/s]` — зачёркивание
- `[size=N]...[/size]` — размер шрифта (диапазон 8–30px)
- `[color=#HEX]...[/color]` — цвет текста (HEX 3 или 6 символов)

### Ссылки и упоминания
- `[url]https://...[/url]` — ссылка, текст = URL
- `[url=https://...]текст[/url]` — ссылка с произвольным текстом
- `[user=userId]Имя[/user]` — упоминание пользователя

### Списки
`[list]` НЕ поддерживается в чат-движке. Вместо него — ручная разметка:
- Маркированный: `• Пункт 1\n• Пункт 2\n• Пункт 3`
- Нумерованный: `1. Пункт один\n2. Пункт два\n3. Пункт три`

### Цитаты и код
- `[code]...[/code]` — блок кода
- `>>текст` — строка цитаты (в начале строки)

### Переносы
- `\n` — перенос строки
- `[br]` — перенос строки (оба варианта работают)

### Чего НЕТ в Битриксе (не использовать):
- `[list]`, `[list=1]` — списки не поддерживаются, используй • или нумерацию вручную
- `[TABLE]`, `[TR]`, `[TD]`, `[TH]` — таблицы не поддерживаются
- `[C]`, `[CODE_INLINE]` — инлайн-кода нет, используй `[b]` или просто текст
- Markdown-разметка любого вида

4. **Выведи пользователю** подтверждение с номером задачи и ссылкой:
   `https://biocard.bitrix24.ru/company/personal/user/169/tasks/task/view/<ID>/`

## Требования к окружению

Скрипт требует переменную окружения `BITRIX_WEBHOOK` (webhook Bitrix24 вида `https://<портал>/rest/<user_id>/<token>/`). Если переменная не задана, скрипт завершится с ошибкой — сообщи пользователю, что нужно задать `BITRIX_WEBHOOK` (см. README репозитория ai_agents_harness). Не пытайся подобрать или захардкодить значение.
